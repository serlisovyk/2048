# Repo map

Orientation in one read — so the code does not have to be rediscovered every session.
Update this file in the same change when a file, module, storage key, or script is
added, removed, renamed, or moved.

## Root files

| File                | What it does                                                                                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.html`        | Page shell: metadata, favicon, Vite entry (`script.js`), score header, empty `.game-grid`, win and game-over overlays, `New Game` button. Board cells are generated by JS, not written in HTML. |
| `script.js`         | The whole game in one ESM module: state, rendering, movement, win/game-over checks, keyboard and pointer input, high score persistence. Imports `styles/main.css`.                              |
| `favicon.svg`       | Source favicon (compact 2x2 board).                                                                                                                                                             |
| `vite.config.js`    | Production build: `@vitejs/plugin-legacy` (targets `defaults, not IE 11`), a custom `minify-html` plugin (`html-minifier-terser`), terser with `drop_console`, no source maps.                  |
| `postcss.config.js` | Autoprefixer.                                                                                                                                                                                   |
| `.prettierrc`       | `singleQuote`, no semicolons, `printWidth: 85`, LF.                                                                                                                                             |
| `.gitattributes`    | Forces LF in the working copy (`core.autocrlf` on Windows otherwise breaks `format:check`).                                                                                                     |
| `AGENTS.md`         | Canonical agent instructions. `CLAUDE.md` points to it.                                                                                                                                         |
| `ai/`               | Agent docs: this map, workflow, rules, decisions, skills, prompt and task templates.                                                                                                            |
| `dist/`             | Generated by `yarn build`. Never edit by hand.                                                                                                                                                  |

## `script.js` layout

Ordered by responsibility, top to bottom:

| Section        | Contents                                                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Constants      | `SIZE` (4), `SWIPE_THRESHOLD` (30px), `ARROWS_KEYS`                                                                                             |
| DOM references | grid, score, high score, overlays, buttons                                                                                                      |
| State          | `board`, `cellElements`, `pointerStart`, `currentScore`, `highScore`, `hasWon`, `isMoving`, `isPausedAfterWin`, `isGameOver`                    |
| Initialization | `createGrid`, `bindEvents`, `initializeGame`, `restartGame`                                                                                     |
| Rendering      | `renderBoard` (sets `data-value`, triggers `new-cell` / `merged-cell` animation classes), `updateScore`                                         |
| Movement       | `move(direction)` → `transform(line, moveTowardsStart)` per row/column, `placeRandom` (90% `2`, 10% `4`)                                        |
| Status checks  | `checkWin` (tile `2048`), `checkGameOver`, `hideWinOverlay`                                                                                     |
| Input          | `handleKeydown` (arrow keys via `event.key`), `handlePointerDown` / `handlePointerUp` (swipe on `.game-grid`), `requestMove` — the single guard |

Known couplings to keep in mind (targets of later tasks): `placeRandom` touches the
DOM (adds `new-cell`); `board.css` hardcodes `repeat(4, …)` instead of following
`SIZE`; timings `100` / `250` ms are literals that mirror CSS durations; overlays are
toggled through `style.display`.

## Styles (`styles/`)

`main.css` imports, in order:

| File           | What it holds                                                        |
| -------------- | -------------------------------------------------------------------- |
| `base.css`     | Reset, body font and colors                                          |
| `layout.css`   | Page layout, score header, `--cell-size` / `--cell-gap`, breakpoints |
| `board.css`    | Grid, cells, `pop-in` / `merge-scale` animations                     |
| `tiles.css`    | Per-value tile colors and font sizes, fallback for larger values     |
| `overlays.css` | Win and game-over overlays                                           |
| `controls.css` | Buttons                                                              |
| `motion.css`   | `prefers-reduced-motion` overrides                                   |

## Storage

| Key         | Value               | Written by    |
| ----------- | ------------------- | ------------- |
| `highScore` | number, as a string | `updateScore` |

Current game state is not persisted.

| `yarn build`        | Production build into `dist/` |
| `yarn preview`      | Serve the production build    |

## Deployment

Vercel Git integration: `main` is the production deployment
(<https://2048-xi-three.vercel.app/>); other pushed branches get preview deployments.
Build command `yarn build`, output `dist/`.

## What this project does NOT have (do not invent it)

- No UI framework, no TypeScript, no CSS preprocessor — see
  `ai/decisions/2026-10-10-vanilla-js-no-framework.md`.
- No automated tests — see `ai/decisions/2026-10-10-no-automated-tests.md`.
- No pull requests — work is merged locally into `main`, see
  `ai/decisions/2026-10-10-local-merge-without-pr.md`.
- No undo, seeded random, move history, PWA, releases, and the other ideas listed in
  `ai/decisions/2026-10-10-rejected-features.md`. Do not propose them again.
- No backend, analytics, or third-party runtime scripts.
