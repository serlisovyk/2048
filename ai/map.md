# Repo map

Orientation in one read — so the code does not have to be rediscovered every session.
Update this file in the same change when a file, class, storage key, or script is
added, removed, renamed, or moved.

## Root files

| File                | What it does                                                                                                                                                                                                                                 |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/`              | All sources: `index.html`, `favicon.svg`, `scripts/`, `styles/`.                                                                                                                                                                             |
| `vite.config.js`    | `root: 'src'`, `publicDir: '../public'` (not created yet), `outDir: '../dist'`; `@vitejs/plugin-legacy` (targets `defaults, not IE 11`), a custom `minify-html` plugin (`html-minifier-terser`), terser with `drop_console`, no source maps. |
| `postcss.config.js` | Autoprefixer. Found by Vite upward from `src/`.                                                                                                                                                                                              |
| `.prettierrc`       | `singleQuote`, no semicolons, `printWidth: 85`, LF.                                                                                                                                                                                          |
| `.gitattributes`    | Forces LF in the working copy (`core.autocrlf` on Windows otherwise breaks `format:check`).                                                                                                                                                  |
| `package.json`      | Scripts, dev dependencies, `"license": "MIT"`, `engines.node`: Node 20.19+ or 22.12+ (the Vite 7 minimum; yarn 1 refuses to install on other versions).                                                                                      |
| `AGENTS.md`         | Canonical agent instructions. `CLAUDE.md` points to it.                                                                                                                                                                                      |
| `ai/`               | Agent docs: this map, workflow, rules, decisions, skills, plans, prompt and task templates.                                                                                                                                                  |
| `dist/`             | Generated by `yarn build`. Never edit by hand.                                                                                                                                                                                               |

## `src/index.html`

Page shell: metadata, favicon (`favicon.svg`, hashed by Vite), entry
`<script type="module" src="./scripts/main.js">`, score header (`.current-score`,
`.high-score`), empty `.game-grid`, win overlay (`.win-overlay`, `.continue-button`),
game-over overlay (`.game-over`, `.restart-game-button`), `.new-game-button`. Board
cells are generated by `GridView`.

## Scripts (`src/scripts/`)

Object-oriented, one class per file — conventions in `ai/rules/oop.md`.

| File                     | Layer            | What it does                                                                                                                                                                                                         |
| ------------------------ | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.js`                | Composition root | Imports `../styles/main.css`; on `DOMContentLoaded` queries the DOM, creates every object, wires `KeyboardInput` / `SwipeInput` to `requestMove` and the buttons to `restart` / `continueAfterWin`, calls `start()`. |
| `constants.js`           | —                | `BOARD_SIZE`, `WIN_TILE`, `SWIPE_THRESHOLD_PX`, `FOUR_TILE_PROBABILITY`, `MOVE_COOLDOWN_MS`, `TILE_ANIMATION_MS`, `ANIMATION_CLEANUP_MS`, `DIRECTIONS`, `ARROW_KEY_DIRECTIONS`, `STORAGE_KEYS`.                      |
| `GameController.js`      | Controller       | `start()`, `restart()`, `continueAfterWin()`, `requestMove(direction)` — the single movement guard (cooldown, pause after win, game over). Keeps the high score and persists it.                                     |
| `game/Board.js`          | Model            | Private grid. `spawnRandomTile()`, `move(direction)` → `{ moved, scoreGained }`, `hasTile(value)`, `hasAvailableMoves()`, `toArray()`. Line sliding in `static #slideLine`.                                          |
| `game/Game.js`           | Model            | One game: board, score, won / over flags. `start()` → `{ spawnedTiles }`, `move(direction)` → `{ moved, scoreGained, spawnedTiles, justWon, isOver }`; getters `cells`, `score`, `isOver`.                           |
| `ui/GridView.js`         | View             | Creates the cells, sets `--board-size` and `--tile-animation-duration` on the grid, `render(values, spawnedTiles)` with `new-cell` / `merged-cell` animation classes, `focus()`.                                     |
| `ui/ScoreView.js`        | View             | `renderScore`, `renderHighScore`.                                                                                                                                                                                    |
| `ui/OverlayView.js`      | View             | `showWin`, `hideWin`, `showGameOver`, `hideAll` (still via `style.display`), `onContinue`, `onRestart`.                                                                                                              |
| `input/KeyboardInput.js` | Input            | Arrow keys (`event.key`) → direction callback.                                                                                                                                                                       |
| `input/SwipeInput.js`    | Input            | Pointer swipe on `.game-grid` above `SWIPE_THRESHOLD_PX` → direction callback.                                                                                                                                       |
| `storage/SafeStorage.js` | Storage          | `getNumber(key, fallback)`, `setValue(key, value)`; returns the fallback / ignores writes when `localStorage` is blocked or throws.                                                                                  |

Known couplings left for later issues: overlays toggle `style.display` and both can
show at once (MY-114); `merged-cell` also fires on a plain slide into an empty cell
(MY-126).

## Styles (`src/styles/`)

`main.css` imports, in order:

| File           | What it holds                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `base.css`     | Reset, body font and colors                                                                                                    |
| `layout.css`   | Page layout, score header, `--cell-size` / `--cell-gap`, breakpoints                                                           |
| `board.css`    | Grid (`repeat(var(--board-size, 4), …)`), cells, `pop-in` / `merge-scale` animations (`var(--tile-animation-duration, 200ms)`) |
| `tiles.css`    | Per-value tile colors and font sizes, fallback for larger values                                                               |
| `overlays.css` | Win and game-over overlays                                                                                                     |
| `controls.css` | Buttons                                                                                                                        |
| `motion.css`   | `prefers-reduced-motion` overrides                                                                                             |

## Storage

| Key (`STORAGE_KEYS`)         | Value               | Written by                         |
| ---------------------------- | ------------------- | ---------------------------------- |
| `HIGH_SCORE` → `'highScore'` | number, as a string | `GameController` via `SafeStorage` |

Current game state is not persisted.

## Deployment

Vercel Git integration: `main` is the production deployment
(<https://2048-xi-three.vercel.app/>); other pushed branches get preview deployments.
Build command `yarn build`, output `dist/`.

## What this project does NOT have (do not invent it)

- No UI framework, no TypeScript, no CSS preprocessor — see
  `ai/decisions/2026-10-10-vanilla-js-no-framework.md`.
- No automated tests — see `ai/decisions/2026-10-10-no-automated-tests.md`.
- No pull requests — work is merged locally into `main`, see
  `ai/decisions/2026-10-10-local-merge-without-pr.md`.
- No undo, seeded random, move history, PWA, releases, and the other ideas listed in
  `ai/decisions/2026-10-10-rejected-features.md`. Do not propose them again.
- No backend, analytics, or third-party runtime scripts.
