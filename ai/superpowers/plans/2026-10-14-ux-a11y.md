## Design

- **`--cell-size`** is the smallest of: the old width preference with a higher ceiling,
  `clamp(60px, 72vw / n, min(128px, 510px / n))` (the board is ~600px at 4×4 and 5×5, 3×3 keeps the 4×4 cell);
  the old fit-the-width term; and a **height term**
  `max(40px, (100svh - rows - (n + 3) * gap) / n)`. `svh`, not `dvh`: a phone's address bar must not resize the board while
  it hides. `rows` is a token on `.game-layout` (`layout.css`) that is the height of everything but the board:
  `2 * padding + 3 * header-gap + 199px`, the 199px being the GitHub row, the two header rows, the footer and the
  record badge's clearance, measured. It over-estimates by up to 16px below 510px wide: a safe side, never a scroll.
- **Short landscape** (`(height <= 570px) and (width >= 540px) and (orientation: landscape)`, in `.game-layout`): a grid, the header and the
  footer in column 1, the board in column 2. In that block `rows` is `2 * padding + 50px` and a `--side-width` token is
  subtracted by the width term, so the board never pushes the page wider than the window. One media query in one rule; the
  formula reads tokens only.
- **Tile tokens** are chosen in OKLCH (hue and chroma kept, lightness moved) so the text is ≥ 4.5:1 against the base and
  the base plus the 14% sheen, neighbours still ≥ 0.048 apart in OKLab; computed with the WCAG formula.
- **Win card**: `--win-bg`'s light end darkened until white is 4.5:1 on it; `dialog p` loses `opacity: 0.95`.
  `--game-over-bg` becomes the opaque colour it looked like.
- **Label style**: one class (`.label`, base file), used by the header's score label and the `dt` of the summary and
  the statistics; its colour in the dialogs is a token `--summary-label` next to `--summary-bg`, both re-pointed for the
  light confirm and settings dialogs in the existing scoped block of `theme.css` (the win and game-over cards keep one look).
- **Icon button**: one class (`.icon-button`) for both trash buttons: a 24px icon in a 30px round button, the 44px hit area
  is a `::after` that extends it, so the shared focus ring (6px beyond the button) stays 42px across and clear of the
  score box's border. The class sets no `display`, so `hidden` keeps working.
- **Statistics** markup: a heading row (`h3` + the muted note, the trash button at the right), then the `dl` as four tiles.
  `data-statistic` and `.reset-statistics-button` stay, so `SettingsView` is not touched.
- **Board name**: `GridView.render` takes `winTile` too and writes `aria-label` (`GameController` passes it; both calls
  of `render` already happen on every size or target change). **Announcement**: `ScoreView.#announce` writes
  `Score N`; the visible score label is `aria-hidden`.
- **GitHub link**: last child of `body`, shown first by `order: -1` (it is a flex item of `body`).
- **Record badge**: a few pixels of space above the score boxes, enough that the badge keeps ≥ 6px from the toolbar.

## What changed while implementing

- **The floor is 40px, not 44px.** At 667×375 the board budget beside the header is 305px; a 5×5 board of 44px cells and
  12px gaps is 316px. 40px is the bottom of the author's 40–48px range and fits (296px). 5×5 at 568×320 still scrolls by
  12px (the width term binds first), a window narrower than 540px falls back to the single column.
- **The landscape query has a width guard**, `(width >= 540px)`: below it `--side-width` made the cell size negative (a
  collapsed board) on landscape windows narrower than about 360px.
- **The icon button is 30px, not 32px**, with `inset: -7px` for the 44px hit area. With 32px a 7-digit high score at 320px
  overflowed its box (the baseline already overflowed by 6px, the button now sits 6px further from the border); the box
  spans both rows so the ring clears the border at every width. A 7-digit high score on a 3×3 board at 320px still
  needs more room than the box has, as before.
- **The score boxes sit 6px lower** (`margin-top` on `.score-container`): the badge's clearance from the toolbar was
  2.7px at 320–375px and is 8.7px now; `--rows-height` went from 193 to 199 with it.
- **Tokens**: the three 14–18px font sizes became one `--font-text` (3vw); the shadow blurs 8, 12 and 15px became one
  `4px 12px` step and the scale was renamed `xs` to `xl` so it has no gap. Two new font tokens, `--font-section` and
  `--font-heading`, and two colour tokens, `--summary-label` and (light settings) a lighter `--summary-bg`.
- **The link preview picture** was remade from the real CSS by a throw-away scene page; rendering the same scene from the
  previous revision's CSS reproduces the committed PNG except for text antialiasing and the logo's glow, so the method is
  sound. The skill's pixel checks pass.
- **`aria-hidden` on the visible Score label** was not in the issue: without it browsing the header reads "Score Score 16".
