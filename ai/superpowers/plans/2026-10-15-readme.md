## 1. The GIF

Recorded from the production build (`yarn build`, then `yarn preview --port 5191`) in a headless Chrome of its own (remote
debugging on 9431, a temporary profile), as a CDP screencast resampled to a fixed frame rate. The game is not touched: the
state is a saved game put into `localStorage` before the page loads, so merges happen at once, and the moves are real key
presses. The encoder (`gifenc`, `pngjs`) and the script live in a temporary folder outside the repo, so `package.json` and
`yarn.lock` stay as they are. Frames are cropped to the game with a small margin and sampled at 20 fps. Each frame stores
only the pixels that changed, with a palette of its own cut from exactly those pixels (a shared 256-colour palette banded
the board's soft shadow).

`docs/` is not in `src/` or `public/`, so the build does not copy it, `.size-limit.json` globs only `dist/assets/`, and Prettier
skips the unsupported `.gif`. The report gives the size, the dimensions, the frame count and the duration.
