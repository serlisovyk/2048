Orientation in one read — so the code does not have to be rediscovered every session.

added, removed, renamed, or moved.

## `src/index.html`

Page shell: metadata (the viewport meta has `viewport-fit=cover`), favicon
(`favicon.svg`, hashed by Vite), entry
`<script type="module" src="./scripts/main.js">`, score header (`.current-score`,
`.high-score`), empty `.game-grid`, three modal `<dialog>`s — win (`.win-overlay`:
`.continue-button`, `.win-restart-button`), game over (`.game-over`:
`.game-over-win-note`, `.restart-game-button`), and the reusable confirmation
(`.confirm-dialog`: `.confirm-title`, `.confirm-message`, `.confirm-cancel-button` with
`autofocus`, `.confirm-accept-button`; texts filled by `ConfirmDialogView`) — and
`.new-game-button`. Board cells are generated by `GridView`. Dialogs:
`ai/decisions/2026-10-10-native-dialog.md`, `ai/decisions/2026-10-10-confirm-dialog.md`.

## Scripts (`src/scripts/`)

Object-oriented, one class per file — conventions in `ai/rules/oop.md`.

| File                      | Layer            | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.js`                 | Composition root | Imports `../styles/main.css`; on `DOMContentLoaded` queries the DOM, creates every object, wires `KeyboardInput` / `SwipeInput` (on the game area, `.game-container`) to `requestMove`, the page `New Game` button to `requestNewGame`, the dialog buttons to `restart` / `continueAfterWin` and the closing of the win and game-over dialogs to `returnFocusToBoard`, calls `start()`.                                                                                                                                                                                                                                                           |
| `constants.js`            | —                | `BOARD_SIZE`, `WIN_TILE`, `SWIPE_THRESHOLD_PX`, `FOUR_TILE_PROBABILITY`, `MOVE_COOLDOWN_MS`, `TILE_ANIMATION_MS`, `ANIMATION_CLEANUP_MS`, `DIRECTIONS`, `KEY_CODE_DIRECTIONS`, `STORAGE_KEYS`, `SAVED_GAME_VERSION`.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GameController.js`       | Controller       | `start()`, `requestNewGame()` (the page `New Game`: asks through `ConfirmDialogView` when `game.isInProgress`, then `restart()` and focus to the board; a "no" gives focus back to the opener, else the board), `restart()` (no question: the win and game-over buttons), `continueAfterWin()`, `returnFocusToBoard()`, `requestMove(direction)` — the single movement guard (cooldown, pause after win, game over); shows one dialog per move (game over wins over win). Keeps the high score and persists it; saves the game after every move that does not end it, restores it in `start()`, deletes it on game over and in `#startNewGame()`. |
| `game/Board.js`           | Model            | Private grid. `spawnRandomTile()`, `move(direction)` → `{ moved, scoreGained }`, `hasTile(value)`, `hasAvailableMoves()`, `toArray()`, `restore(cells)` (validates size and tile values, `true`/`false`). Line sliding in `static #slideLine`.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `game/Game.js`            | Model            | One game: board, score, won / over flags. `start()` → `{ spawnedTiles }`, `move(direction)` → `{ moved, scoreGained, spawnedTiles, justWon, isOver }`; getters `cells`, `score`, `isOver`, `isInProgress` (a move was made and the game is not over; a restored game counts; never stored); `toState()` → `{ board, score, hasWon }`, `restore(state)` → `true`/`false` (rejects a bad state or a board with no moves).                                                                                                                                                                                                                           |
| `ui/GridView.js`          | View             | Creates the cells, sets `--board-size` and `--tile-animation-duration` on the grid, `render(values, spawnedTiles)` with `new-cell` / `merged-cell` animation classes, `focus()`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `ui/ScoreView.js`         | View             | `renderScore`, `renderHighScore`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `ui/OverlayView.js`       | View             | Owns the win and game-over `<dialog>`s: `showWin`, `showGameOver({ justWon })` (`showModal()`, closes the other one first), `hideWin`, `hideAll` (`close()`); `onContinue` (button and `Escape` on the win dialog), `onRestart` (both restart buttons), `onClose` (any close). Game over ignores `Escape`.                                                                                                                                                                                                                                                                                                                                        |
| `ui/ConfirmDialogView.js` | View             | Owns the reusable confirmation `<dialog>`: `ask({ title, message, confirmLabel, cancelLabel })` → `Promise<boolean>` (`true` only for the confirm button; `Cancel`, `Escape` and a forced close give `false`; `Cancel` has the initial focus), `restoreFocus()` (back to the element that was focused when the question was asked, `false` if it cannot take focus). Knows no caller: `GameController` supplies the wording.                                                                                                                                                                                                                      |
| `input/KeyboardInput.js`  | Input            | Arrows and WASD by `event.code` (`KEY_CODE_DIRECTIONS`, any layout) → direction callback; skips Ctrl / Meta / Alt combos and keys from form fields or dialogs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `input/SwipeInput.js`     | Input            | Pointer swipe on the game area (`.game-container`: the grid and its padding) above `SWIPE_THRESHOLD_PX` → direction callback; never `preventDefault`s, so taps on buttons still click.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `storage/SafeStorage.js`  | Storage          | `getNumber(key, fallback)`, `getJson(key)` (`null` when missing or corrupted), `setValue(key, value)`, `setJson(key, value)`, `remove(key)`; returns the fallback / ignores writes when `localStorage` is blocked or throws.                                                                                                                                                                                                                                                                                                                                                                                                                      |

Known coupling left for a later issue: `merged-cell` also fires on a plain slide into
an empty cell (MY-126).

## Styles (`src/styles/`)

`main.css` imports, in order:

| File           | What it holds                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `base.css`     | Reset, body font and colors, `overscroll-behavior-y`, page `touch-action`                                                      |
| `layout.css`   | Page layout, safe-area body padding, score header, `--cell-size` / `--cell-gap`, game area `touch-action`, breakpoints         |
| `board.css`    | Grid (`repeat(var(--board-size, 4), …)`), cells, `pop-in` / `merge-scale` animations (`var(--tile-animation-duration, 200ms)`) |
| `tiles.css`    | Per-value tile colors and font sizes, fallback for larger values                                                               |
| `overlays.css` | Win, game-over, and confirmation `<dialog>`s: `[open]` layout, `dialog::backdrop`, `modal-pop` / `backdrop-fade`               |
| `controls.css` | Buttons (the dialogs' primary white and secondary outlined looks), the dialog button row (`.dialog-actions`)                   |
| `motion.css`   | `prefers-reduced-motion` overrides                                                                                             |

Touch and safe areas: `html` and `body` have `overscroll-behavior-y: none` and
`touch-action: manipulation`; `.game-container` (the swipe surface) has
`touch-action: none` and `user-select: none`; the body padding on each side is
`max(var(--page-padding), env(safe-area-inset-<side>, 0px))`. Why page zoom stays
available: `ai/decisions/2026-10-10-no-viewport-zoom-lock.md`. `main.js` hands `SwipeInput`
the same `.game-container`: if the swipe surface ever changes, move `touch-action` with
it, or swipes that start outside the `none` region die in a scroll.

## Storage

| Key (`STORAGE_KEYS`)         | Value                                    | Written by                         |
| ---------------------------- | ---------------------------------------- | ---------------------------------- |
| `HIGH_SCORE` → `'highScore'` | number, as a string                      | `GameController` via `SafeStorage` |
| `SAVED_GAME` → `'savedGame'` | JSON `{ version, board, score, hasWon }` | `GameController` via `SafeStorage` |

The saved game (`SAVED_GAME_VERSION` = 1, always 4x4 / win tile 2048) is written after
every successful move, deleted on game over, `New Game`, `Restart Game`, and when it
fails validation on load — a finished game is never stored. The model validates the
board, the controller checks the version. Format and rules:
`ai/decisions/2026-10-10-saved-game-format.md`.

## What this project does NOT have (do not invent it)

- No UI framework, no TypeScript, no CSS preprocessor — see
  `ai/decisions/2026-10-10-vanilla-js-no-framework.md`.
- No automated tests — see `ai/decisions/2026-10-10-no-automated-tests.md`.
- No pull requests — work is merged locally into `main`, see
  `ai/decisions/2026-10-10-local-merge-without-pr.md`.
- No undo, seeded random, move history, PWA, releases, and the other ideas listed in
  `ai/decisions/2026-10-10-rejected-features.md`. Do not propose them again.
- No backend, analytics, or third-party runtime scripts.
